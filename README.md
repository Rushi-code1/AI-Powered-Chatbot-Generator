## 🚀 Features

- **Custom Intent Modeling** — Easily configure custom JSON training sets with diverse intent patterns, keywords, and contextual responses.
- **NLP Preprocessing Pipeline** — Tokenization, lower-casing, punctuation stripping, and keyword probability extraction.
- **Confidence Scoring & Smart Fallback** — Probabilistic scoring algorithm that triggers smart fallback responses when query ambiguity is high.
- **Embeddable Chat Interface** — Drop-in web widget with auto-scrolling conversation log, typing indicators, and clean bubble styling.
- **Zero Heavy GPU Dependency** — Pure lightweight CPU execution designed for ultra-low latency and minimal resource usage.

---

## 🛠️ Tech Stack

- **Language:** Python 3.12
- **NLP & Classification:** Custom tokenization, keyword matching, intent scoring
- **Storage:** JSON knowledge-base & SQLite interaction log
- **Frontend Widget:** HTML5, CSS3, JavaScript Fetch client
